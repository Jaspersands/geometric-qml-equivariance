## Physics in one paragraph

For an isotropic Heisenberg Hamiltonian $H = J\sum_{\langle ij\rangle}\vec\sigma_i\cdot\vec\sigma_j$ the total spin $\vec S = \tfrac12\sum_i\vec\sigma_i$ is conserved. Gates generated by the exchange operators $G_{ij} = X_iX_j+Y_iY_j+Z_iZ_j$ commute with $\vec S$, so an ansatz $\prod\exp(-i\theta\,G_{ij})$ started in a product of Bell singlets never leaves the $S=0$ sector, whose dimension is the Catalan number $C_{N/2}\ll 2^N$. By Schur–Weyl duality the exchange operators span the commutant of SU(2), and their Lie closure is

$$\mathfrak g_{\text{EQNN}} \;=\; \bigoplus_S \mathfrak{su}(m_S)\;\oplus\;\text{(one central element)},\qquad \dim\mathfrak g = \sum_S (m_S^2-1)+1,$$

with $m_S$ the multiplicity of the spin-$S$ irrep. `equivariant_dla_dimension_formula` evaluates this and `analyze_ansatz` verifies it numerically: **1, 12, 129** for $N = 2, 4, 6$ (versus $4^N-1 = 15, 255, 4095$ for a hardware-efficient ansatz, which closes to the full $\mathfrak{su}(2^N)$). Because $m_S$ grows like a Catalan number the DLA is exponentially *smaller* than $\mathfrak{su}(4^N)$ but not polynomial — full barren-plateau freedom needs additional symmetry (e.g. $S_N$ weight sharing, Schatzki et al. 2022). The README of v0.2 claimed a polynomial DLA; that claim is withdrawn.

## What the package does

| Module | Capability |
|---|---|
| `models` | `lattice_edges` (chain, ring, rectangular grid, triangular ladder, kagome), `HeisenbergSpinChain` with a PennyLane-free dense matrix, SU(2) generators, Casimir, `total_spin_sectors`, singlet product state |
| `ansatz` | `EquivariantQuantumAnsatz`, `HardwareEfficientAnsatz`, `QAOABaselineAnsatz` — each with `apply_circuit` (PennyLane), `generators()` and a dense `unitary(params)` |
| `dla` | `DynamicalLieAlgebraAnalyzer` (traceless generators, incremental commutator closure, dimension cap), `analyze_ansatz`, `equivariant_dla_dimension_formula` |
| `barren_plateau` | `GradientVarianceAnalyzer` (backprop gradients at random parameters), `run_barren_plateau_scaling_study` (depth $L=N$ or fixed; per-bond normalisation), `fit_variance_scaling` |
| `vqe` | `EquivariantVQE` — seeded Adam, energy history, `singlet_purity` diagnostic, any lattice |
| `fermi_hubbard` | Jordan–Wigner `FermiHubbardChain` (dense + PennyLane), `spin_generators`, `charge_generators` (η-pairing), particle-hole-symmetric form, sector ground energies |
| `qgnn` | `QuantumGraphNeuralNetwork` — layers are single exponentials of the graph Heisenberg Hamiltonian, so `is_permutation_equivariant` holds exactly for graph automorphisms |
| `sycamore_transpile` | exact $\exp(-i\theta G_{ij}) = \mathrm{FSim}(2\theta,0)\cdot\mathrm{CNOT}\,R_z(2\theta)\,\mathrm{CNOT}$, `PhasedFSimGate` option, snake placement with adjacency checks |
| `export_openfermion` | JSON term list, OpenFermion `QubitOperator` string, Qiskit `SparsePauliOp` list |
| `cli` | `geometric-qml variance | dla | sectors | transpile | vqe | benchmark` (all `--json`) |

## Quickstart

```python
import numpy as np
from geometric_qml import (
    HeisenbergSpinChain, EquivariantQuantumAnsatz, HardwareEfficientAnsatz,
    analyze_ansatz, equivariant_dla_dimension_formula, total_spin_sectors,
    run_barren_plateau_scaling_study, EquivariantVQE, SycamoreEquivariantTranspiler,
)

# Total-spin sectors and the singlet (Catalan) dimension
print(total_spin_sectors(6))                       # {0.0: 5, 1.0: 9, 2.0: 5, 3.0: 1}

# DLA closure vs the closed form
res = analyze_ansatz(EquivariantQuantumAnsatz(n_qubits=6, n_layers=1, weight_sharing=False))
print(res["dla_dimension"], equivariant_dla_dimension_formula(6))   # 129 129
print(analyze_ansatz(HardwareEfficientAnsatz(n_qubits=3, n_layers=1))["dla_dimension"])  # 63 = su(8)

# Barren plateaus: depth L = N, HEA decays as 2^(-0.7 N), EQNN per-bond variance polynomially
study = run_barren_plateau_scaling_study(qubit_list=[4, 6, 8], depth="linear", n_samples=30)
print(study["fits_mean"]["hea"]["slope_log2"], study["fits_mean"]["equivariant"]["slope_log2"])

# Equivariant VQE on a 4-site chain (exact E0 = -6.4641)
vqe = EquivariantVQE(n_qubits=4, n_layers=3, seed=1).train(steps=80)
print(vqe["final_energy"], vqe["singlet_purity"])

# Sycamore: 8 qubits in a snake, every chain bond physically adjacent
tr = SycamoreEquivariantTranspiler(n_qubits=8)
print(tr.gate_counts(tr.transpile_circuit(n_layers=2, params=np.array([0.3, 0.5]))))
```

```bash
geometric-qml dla --ansatz equivariant --qubits 6 --lattice ring
geometric-qml sectors --qubits 8
geometric-qml benchmark --quick
```

## Honest notes

* Gradient variances of different ansätze are not directly comparable — a shared EQNN angle multiplies a sum over $N-1$ bonds, so its raw variance grows with $N$. The study therefore reports the per-bond variance and the *scaling exponent*, which is what matters for trainability.
* At fixed shallow depth (e.g. $L=2$) nothing plateaus; barren plateaus are a property of depth growing with $N$, and $N=2$ is degenerate for the EQNN (the singlet is the unique $S=0$ state, so the cost is constant). Defaults avoid both traps.
* The "Sycamore" circuits use `FSimGate`/`PhasedFSimGate` with arbitrary angles; real hardware exposes a fixed native angle (see the companion `cirq-fsim-compiler` for calibrated synthesis).
